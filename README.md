# KeyCraft

Ein lokaler Passwort-Generator ohne Backend. Öffne `index.html` direkt im Browser.

## Funktionen

- Kryptografisch sichere Zufallswerte mit `window.crypto.getRandomValues()`
- Längen-Presets für 32, 64 und 128 Zeichen sowie frei wählbare Länge
- Klein-/Großbuchstaben, Zahlen, Sonderzeichen und Ausschluss ähnlicher Zeichen
- Stärke, Entropie und geschätzte Knackzeit
- Ein-Klick-Kopieren und Export von bis zu 500 Passwörtern als TXT-Datei

Passwörter werden ausschließlich im Browser erzeugt und verlassen das Gerät nicht.
